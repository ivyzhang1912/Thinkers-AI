# Thinkers：中国思想史领域大语言模型

Thinkers 是面向中国思想史领域的大语言模型。本仓库为项目实验模块的代码，覆盖从古籍文本到指令微调数据的构建流程，以及模型推理与评测。

## 项目概况

- 语料：《中国思想家评传》丛书，约 4,359 万字，共 200 余部
- 数据：构建约 175 万条指令微调数据
- 训练：以百川（Baichuan）为基座，依次进行继续预训练、监督微调（SFT）和 DPO
- 结果：在自动指标与专家评测上均优于三个开源基线模型

## 仓库结构

| 目录 | 内容 |
|---|---|
| `1_XML解析与文本合并` | 从丛书 XML 中抽取正文与注释，合并正文 |
| `2_问句构建` | 滑动窗口切分正文（5 句一组、组间重叠、单段不超过 400 字） |
| `3_问答对生成` | 调用 GPT-3.5 基于文本段生成多轮问答 |
| `4_相似度计算与去重` | 基于 Sentence-Transformers 计算问句相似度 |
| `5_问答数据整合` | 合并相似度高于 0.95 的问答；`整合统计.csv` 为各书整合前后的问句数 |
| `6_微调数据集构建` | 转换为 instruction / input / output 格式并输出 JSON |
| `7_模型推理与评测` | 抽取评测样本、批量推理、计算 ROUGE 与 BLEU |
| `8_演示视频` | 模型问答演示 |

## 环境与运行

- Python 3，主要依赖：`openai`、`jionlp`、`pandas`、`sentence-transformers`、`scikit-learn`、`transformers`、`rouge_chinese`、`nltk`、`llmtuner`
- 调用 OpenAI 的脚本从环境变量 `OPENAI_API_KEY` 读取密钥
- 脚本中的文件路径为原始开发环境路径，运行前需按本地目录修改
