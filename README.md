# Thinkers：中国思想史领域大语言模型

这是我在 Thinkers 项目里负责的实验模块代码。项目想做的是一个懂中国思想史的大模型：问它“黄宗羲为什么说‘天下为主，君为客’”，它能把这条思想脉络讲清楚，而不是只拼凑几个知识点。

我主要负责数据这一头，从古籍文本一路做到可以直接拿去微调的指令数据，后面也参与了模型评测。

## 做了什么

- 语料来自《中国思想家评传》丛书，约 4,359 万字，共 200 余部思想家评传
- 用这些文本构建了约 175 万条指令微调数据
- 以百川（Baichuan）为基座，依次做了继续预训练、监督微调和 DPO
- 训练后的模型在自动指标和专家评测上都超过了三个开源基线模型

## 仓库结构

按处理顺序编号，基本上一个文件夹就是流水线里的一步：

```
1_XML解析与文本合并/     从丛书的 XML 里抽出正文和注释，再把正文合并
2_问句构建/              用滑动窗口把正文切成段落（5 句一组，组间重叠，单段不超过 400 字）
3_问答对生成/            调用 GPT-3.5 根据每段文本生成多轮问答
4_相似度计算与去重/      用 Sentence-Transformers 算问句之间的相似度，找出重复的问题
5_问答数据整合/          把相似度高于 0.95 的问答交给模型合并，整合统计.csv 记录了每本书整合前后的问句数
6_微调数据集构建/        转成 instruction / input / output 格式，打乱后输出 JSON
7_模型推理与评测/        抽样评测集，批量推理，再算 ROUGE 和 BLEU
8_演示视频/              模型的问答演示
```

## 几点说明

- **数据没有放上来。** 原始语料和生成的问答数据涉及版权和隐私，只能放处理代码。
- **训练脚本不在这里。** 继续预训练、SFT 和 DPO 是在实验室服务器上用 LLaMA-Factory 跑的，配置文件没有整理进来，所以第 6 步和第 7 步之间少了训练这一环。
- 代码里的路径都是我当时在本机和服务器上的路径，直接运行需要改成自己的。
- 调用 OpenAI 的脚本从环境变量 `OPENAI_API_KEY` 读取密钥。

## 回头看

做完这个项目，我最大的感受是：模型分数上去了，我却说不清它为什么有效。哪些数据真的起了作用，哪些问答其实在“教坏”模型，当时都是凭经验判断。这也是我后来去做大模型评测、想把模型为什么可靠弄明白的起点。
