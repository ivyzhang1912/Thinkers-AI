# Thinkers：中国思想史领域大语言模型

Thinkers 是面向中国思想史领域的大语言模型，以《中国思想家评传》丛书为语料构建训练数据，基于 Baichuan2-7B-Chat 经继续预训练、监督微调和 DPO 训练得到。本仓库包含语料处理、指令微调数据构建、偏好数据构建、DPO 训练记录及模型评测代码。

## 项目概况

- 语料：《中国思想家评传》丛书，约 4,359 万字，共 201 部（目录见 `00_语料目录`）
- 数据：构建约 175 万条指令微调数据
- 基座：Baichuan2-7B-Chat
- 训练：继续预训练、监督微调（SFT）、DPO，基于 LLaMA-Factory 完成
- 结果：在自动指标与专家评测上均优于三个开源基线模型

## 仓库结构

| 目录 | 内容 |
|---|---|
| `00_语料目录` | 《中国思想家评传》丛书书目 |
| `01_XML解析与文本合并` | 从丛书 XML 中抽取正文与注释，合并正文 |
| `02_问句构建` | 滑动窗口切分正文（5 句一组、组间重叠、单段不超过 400 字） |
| `03_问答对生成` | 调用 GPT-3.5 基于文本段生成多轮问答 |
| `04_相似度计算与去重` | 基于 Sentence-Transformers 计算问句相似度 |
| `05_问答数据整合` | 合并相似度高于 0.95 的问答；`整合统计.csv` 为各书整合前后的问句数 |
| `06_微调数据集构建` | 转换为 instruction / input / output 格式并输出 JSON |
| `07_偏好数据构建_RLAIF` | 抽取问答样本，由 GPT-3.5 基于原文生成按质量分级的候选回答，结合微调模型的回答，转换为 DPO 所需的排序数据 |
| `08_DPO训练` | DPO 训练配置与日志：LoRA 配置、训练结果、训练过程记录、loss 曲线 |
| `09_模型推理与评测` | 抽取评测样本、批量推理、计算 ROUGE 与 BLEU（整体与逐条） |
| `10_演示视频` | 模型问答演示 |

## DPO 训练设置

| 项目 | 设置 |
|---|---|
| 基座模型 | Baichuan2-7B-Chat |
| 微调方式 | LoRA（r=8，alpha=32，dropout=0.1，target_modules=W_pack） |
| 训练轮数 | 1 epoch，共 1,288 步 |
| 最终 train loss | 0.516 |
| 框架 | LLaMA-Factory 0.1.8，PEFT 0.5.0 |

## 环境与运行

- Python 3，主要依赖：`openai`、`jionlp`、`pandas`、`sentence-transformers`、`scikit-learn`、`transformers`、`peft`、`rouge_chinese`、`nltk`、`llmtuner`、`pyautogui`
- 调用 OpenAI 的脚本从环境变量 `OPENAI_API_KEY` 读取密钥
- 脚本中的文件路径为原始开发环境路径，运行前需按本地目录修改
